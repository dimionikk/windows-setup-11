# windows-setup-11

Знімок налаштувань Windows перед переустановкою. Свідомо збирає лише головне,
потрібне для переустановки, — без нішевих категорій (тема, реєстрові твіки,
принтери/VPN/Wi-Fi, Steam тощо). Таке рідкісне легше налаштувати вручну самому.

## Як користуватись

Запусти `Menu.cmd` — відкриється звичайне клікабельне вікно (Python/Tkinter), усе робиться звідти:

1. **Зробити знімок системи** — діалог із чекбоксами по кожному пункту (залізо,
   програми, конфіги, компоненти Windows, згруповані по категоріях; "Обрати все" /
   "Зняти все"), плюс куди зберегти, .zip, -Redact — і живий лог виконання
2. **Встановити зі знімка** — обираєш папку `SystemSnapshot_*`, меню читає, що в ній
   є, і показує чекбокси по кожному конкретному пункту: кожен winget-пакет, кожне
   розширення VS Code, і окремо — кожен конфіг-файл, hosts, компоненти Windows.
   Постав галку тільки на те, що дійсно треба, — решта не зміниться. Пакети й
   розширення за замовчуванням увімкнені (безпечно, лише ставлять); конфіги/hosts/
   компоненти Windows — вимкнені (перезаписують живі файли чи налаштування) і при
   встановленні автоматично бекапляться (`*.bak-<час>` поруч із файлом)
3. **Встановити залежності** — так само чекбоксами: розблокувати файли репозиторію,
   виправити ExecutionPolicy, перевірити/відновити winget, поставити PowerShell 7
4. Відкрити останній знімок
5. Відкрити папку SystemSnapshot
6. Показати цю інструкцію

Пункти, що потребують прав адміністратора (компоненти Windows, драйвери, hosts), у діалогах
недоступні (сірі), якщо сесія без адмін-прав — усе одно будуть пропущені скриптом.

При відкритті меню одразу з'являється запит UAC (потрібен для компонентів Windows і драйверів);
далі всі дії виконуються без повторних запитів.

Знімок робить папку `SystemSnapshot_*`. Знімки приватні й у репозиторій не потрапляють (`.gitignore`).

## Що збирається

Залізо/ОС/диски, встановлені програми (реєстр + winget-експорт), розширення VS Code,
змінні середовища, автозапуск (реєстр + Startup), hosts-файл, конфіги (git, SSH,
PowerShell-профіль, Windows Terminal, VS Code), і від адміністратора — увімкнені
компоненти Windows та сторонні драйвери. Автоматично генеруються README.md,
ЩО-ВСТАНОВИТИ.txt і скан на випадково зібрані секрети/паролі.

Усе інше (тема й шпалери, реєстрові твіки, принтери, VPN, Wi-Fi, WSL, мережеві диски,
заплановані задачі, служби, схема живлення, шрифти, Chocolatey/Scoop, PowerShell-модулі,
pip/npm-пакети, конфіги OBS/Notepad++/qBittorrent, ігри Steam) — свідомо не збирається.
За потреби постав/подивись вручну.

## Файли

| Файл | Що |
|---|---|
| `Menu.cmd` | єдина точка входу — запускає `menu.pyw` |
| `menu.pyw` | GUI-меню (Tkinter): кнопки, діалоги опцій, вікно з логом виконання |
| `Setup.ps1` | логіка встановлення залежностей (`Invoke-DependencySetup`) |
| `Take-SystemSnapshot.ps1` | логіка знімка системи (`Invoke-SystemSnapshot`) |
| `Restore-SystemSnapshot.ps1` | логіка відновлення зі знімка (`-List` — що є в знімку; `-Steps` — що встановити) |

Усі три `.ps1`-файли можна запускати і напряму з PowerShell з аргументами (наприклад
`.\Take-SystemSnapshot.ps1 -Zip -Redact -NoPrompt` або
`.\Restore-SystemSnapshot.ps1 -SnapshotDir .\SystemSnapshot_2026-01-01_120000 -Steps winget:Git.Git`),
якщо потрібна автоматизація без GUI.
Потрібен встановлений Python 3 (є tkinter у стандартній поставці з python.org).
