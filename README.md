# windows-setup-11

Знімок налаштувань Windows перед переустановкою: програми, git-репозиторії,
розширення програм, налаштування, візуальне оформлення. Без заліза/GPU/батареї,
реєстру, драйверів, автозапуску — це простіше налаштувати вручну. Адмін-права
не потрібні.

## Користування

Запусти `Menu.cmd` — GUI-меню (Python/Tkinter). Залежності підтягуються самі:
якщо немає Python, `Menu.cmd` сам спитає дозволу поставити його через winget
(і полагодить сам winget за потреби) — після встановлення досить відкрити
`Menu.cmd` ще раз. Якщо Python уже є, а winget — ні, про це спитає вже саме
меню одразу при відкритті. Якщо все на місці — меню просто відкривається,
без жодних питань.

1. **Зробити знімок** — чекбокси категорій, папка збереження, лог виконання.
   Якщо обрано git-репозиторії — окремо питає, на яких дисках шукати.
2. **Встановити зі знімка** — обираєш папку `SystemSnapshot_*`, меню показує
   чекбокси по кожному пункту (пакет, розширення, файл, репозиторій, оформлення).
   Пакети й розширення увімкнені за замовчуванням (безпечно). Налаштування й
   оформлення — вимкнені (можуть перезаписати поточне), при встановленні
   автоматично бекапляться (`*.bak-<час>` для файлів, `SystemSnapshot-visual-backup-<час>`
   на робочому столі для оформлення). Репозиторії клонуються лише в нову
   папку — якщо вже є, пункт пропускається.
3. **Встановити залежності** — чекбоксами: розблокувати файли, виправити
   ExecutionPolicy, перевірити/відновити winget, поставити PowerShell 7.
4. Відкрити останній знімок / папку SystemSnapshot / це README.

Знімок зберігається в `SystemSnapshot_*` на робочому столі. Знімки не
потрапляють у репозиторій (`.gitignore`).

## Що збирається

| Категорія | Файл |
|---|---|
| Програми | `programs.json` (winget export) + `programs-all.csv` (повний реєстровий список) |
| Розширення VS Code | `vscode-extensions.txt` |
| Налаштування | `.gitconfig`, `.ssh\config`, профіль PowerShell, Windows Terminal, VS Code |
| Git-репозиторії | `repos.csv` — шлях + origin кожного знайденого репо |
| Візуальне оформлення | шпалина, тема, колір акценту, панель задач, Провідник |

Свідомо не збирається: принтери, VPN, Wi-Fi, WSL, мережеві диски, заплановані
задачі, служби, схема живлення, шрифти, Chocolatey/Scoop, PowerShell-модулі,
pip/npm-пакети, конфіги OBS/Notepad++/qBittorrent, Steam, компоненти Windows,
драйвери.

## Файли

| Файл | Що |
|---|---|
| `Menu.cmd` | точка входу — запускає `menu.pyw` |
| `menu.pyw` | GUI (Tkinter): кнопки, діалоги, лог виконання |
| `Setup.ps1` | встановлення залежностей (`Invoke-DependencySetup`) |
| `Take-SystemSnapshot.ps1` | створення знімка (`Invoke-SystemSnapshot`) |
| `Restore-SystemSnapshot.ps1` | відновлення зі знімка (`-List` / `-Steps`) |

Кожен `.ps1` можна запускати напряму з аргументами, наприклад:
```
.\Take-SystemSnapshot.ps1 -RepoDrives C: -NoPrompt
.\Restore-SystemSnapshot.ps1 -SnapshotDir .\SystemSnapshot_2026-01-01_120000 -Steps winget:Git.Git
```

Потрібен Python 3 (з tkinter — є в стандартній збірці з python.org).
