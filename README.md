# windows-setup-11

Знімок налаштувань Windows перед переустановкою.

1. `Встановити залежності.cmd` — один раз на новій системі (winget, PowerShell 7).
2. `Зробити знімок.cmd` — робить папку `SystemSnapshot_*` на робочому столі
   (список програм, конфіги, тема, драйвери, план відновлення).

Знімки приватні й у репозиторій не потрапляють (`.gitignore`).
