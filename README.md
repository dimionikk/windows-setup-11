# windows-setup-11

Знімок налаштувань Windows перед переустановкою. Лише те, що реально треба, щоб
не гаяти час на пошук всього заново: програми, git-репозиторії, розширення
програм, налаштування і візуальне оформлення. Ніяких заліза/GPU/батареї,
компонентів реєстру, драйверів чи автозапуску — це рідкісне легше налаштувати
вручну самому. Права адміністратора не потрібні.

## Як користуватись

Запусти `Menu.cmd` — відкриється звичайне клікабельне вікно (Python/Tkinter), усе робиться звідти:

1. **Зробити знімок системи** — діалог із чекбоксами по кожній категорії, куди
   зберегти, і живий лог виконання. Якщо серед категорій обрано git-репозиторії —
   окремо спитає, на яких дисках їх шукати.
2. **Встановити зі знімка** — обираєш папку `SystemSnapshot_*`, меню читає, що в
   ній є, і показує чекбокси по кожному конкретному пункту: кожен winget-пакет,
   кожне розширення VS Code, кожен файл налаштувань, кожен репозиторій, візуальне
   оформлення окремо. Постав галку тільки на те, що дійсно треба. Пакети й
   розширення за замовчуванням увімкнені (безпечно, лише ставлять); налаштування
   і візуальне оформлення — вимкнені (можуть перезаписати поточне) і при
   встановленні автоматично бекапляться (файли — `*.bak-<час>` поруч із файлом,
   реєстр візуального оформлення — папка `SystemSnapshot-visual-backup-<час>` на
   робочому столі). Репозиторії клонуються лише в нову папку — якщо вона вже є,
   пункт просто пропускається, нічого не перезаписуючи.
3. **Встановити залежності** — так само чекбоксами: розблокувати файли репозиторію,
   виправити ExecutionPolicy, перевірити/відновити winget, поставити PowerShell 7.
4. Відкрити останній знімок
5. Відкрити папку SystemSnapshot
6. Показати цю інструкцію

Знімок робить папку `SystemSnapshot_*` на робочому столі. Знімки приватні й у
репозиторій не потрапляють (`.gitignore`).

## Що збирається

- **Програми** — `programs.json` (winget export, перевстановлення однією командою)
  + `programs-all.csv` (повний реєстровий список, для звірки).
- **Розширення VS Code** — `vscode-extensions.txt`.
- **Налаштування** — `.gitconfig`, `.ssh\config`, профіль PowerShell, Windows
  Terminal, VS Code (`settings.json` / `keybindings.json` / snippets).
- **Git-репозиторії** — `repos.csv`: шлях і адреса `origin` для кожного
  знайденого локального репозиторію (на обраних дисках), для повторного
  `git clone`.
- **Візуальне оформлення** — шпалина, світла/темна тема, колір акценту, панель
  задач (положення/автоприховування/віджети/пошук), налаштування Провідника.

Усе інше (принтери, VPN, Wi-Fi, WSL, мережеві диски, заплановані задачі, служби,
схема живлення, шрифти, Chocolatey/Scoop, PowerShell-модулі, pip/npm-пакети,
конфіги OBS/Notepad++/qBittorrent, ігри Steam, компоненти Windows, драйвери) —
свідомо не збирається. За потреби постав/подивись вручну.

## Файли

| Файл | Що |
|---|---|
| `Menu.cmd` | єдина точка входу — запускає `menu.pyw` |
| `menu.pyw` | GUI-меню (Tkinter): кнопки, діалоги опцій, вікно з логом виконання |
| `Setup.ps1` | логіка встановлення залежностей (`Invoke-DependencySetup`) |
| `Take-SystemSnapshot.ps1` | логіка знімка системи (`Invoke-SystemSnapshot`) |
| `Restore-SystemSnapshot.ps1` | логіка відновлення зі знімка (`-List` — що є в знімку; `-Steps` — що встановити) |

Усі три `.ps1`-файли можна запускати і напряму з PowerShell з аргументами (наприклад
`.\Take-SystemSnapshot.ps1 -RepoDrives C: -NoPrompt` або
`.\Restore-SystemSnapshot.ps1 -SnapshotDir .\SystemSnapshot_2026-01-01_120000 -Steps winget:Git.Git`),
якщо потрібна автоматизація без GUI.
Потрібен встановлений Python 3 (є tkinter у стандартній поставці з python.org).
